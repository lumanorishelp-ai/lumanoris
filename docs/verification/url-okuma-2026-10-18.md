## Düzeltmeden önce

Aynı 20 site, IPv4 düzeltmesinden önceki ilk koşuda:
- 9'u 0–1 ms içinde "bağlantı" hatası verdi. Bunlar blog.cloudflare.com, medium.com, www.cloudflare.com, eksisozluk.com, web.whatsapp.com, developer.mozilla.org, http://wikipedia.org, şemasız Wikipedia adresi ve w3.org PDF bağlantısıydı.
- Neden: kod alan adının IPv6 adreslerini de sabitliyordu; IPv6 yolu olmayan makinede bağlantı anında düşüyordu.
- Eski kodda yönlendirme de hiç izlenmiyordu, kimlik olarak `LumanorisBot/1.0` gönderiliyordu ve yalnızca iki genel hata mesajı vardı.

## Hata sınıfları ve mesajlar

| reason | Kullanıcıya gösterilen |
|---|---|
| `dns` | Siteye ulaşılamadı: alan adı bulunamadı. Adresi kontrol edin. |
| `timeout` | Siteye ulaşılamadı: site 15 saniye içinde yanıt vermedi. Biraz sonra tekrar deneyin. |
| `connect` | Siteye ulaşılamadı: sunucu bağlantıyı kabul etmedi. |
| `ssl` | Siteye güvenli bağlantı kurulamadı (SSL sertifikası geçersiz ya da eski). |
| `private` | Bu adres taranamaz (iç ağ adresleri engellidir). |
| `blocked` | Site otomatik erişimi engelledi (bot koruması). Sayfadaki metni kopyalayıp "Metin ekle" ile ekleyebilirsiniz. |
| `auth` | Bu sayfa giriş yapmayı gerektiriyor; içeriği okunamadı. |
| `not_found` | Sayfa bulunamadı (404). Adresi kontrol edin. |
| `server_error` | Site şu anda hata veriyor (5xx). Biraz sonra tekrar deneyin. |
| `pdf` | Bu bağlantı bir PDF dosyası. Dosyayı indirip "Belge yükle" ile ekleyin. |
| `unsupported_type` | Bu bağlantı bir web sayfası değil (tür); desteklenmeyen içerik türü. |
| `js_rendered` | Sayfa içeriği tarayıcıda JavaScript ile oluşturuluyor ve okunamadı. Metni kopyalayıp "Metin ekle" ile ekleyebilirsiniz. |
| `empty` | Sayfada okunabilir metin bulunamadı. |
| `too_large` | Sayfa çok büyük (en fazla 3 MB). |
| `too_many_redirects` | Sayfa çok fazla yönlendirme yaptı; içerik okunamadı. |
| `char_limit` (ekleme) | Karakter sınırı aşılıyor: bu kaynak X karakter, bilgi bankasında Y / 60.000 karakter var (kalan Z). Daha kısa bir kaynak seçin. |
